プライバシーポリシー

制定日　2026年11月27日

QuizBingo 運営者（以下「運営者」といいます）は、ゲームサービス「QuizBingo（クイズビンゴ）」（以下「本サービス」といいます）で取り扱う個人情報を、個人情報の保護に関する法律その他の関係法令に従い、次のとおり取り扱います。用語の定義は利用規約によります。

1事業者

個人情報取扱事業者は、QuizBingo 運営者です。運営者の氏名、住所および代表者の氏名は、本人からの求めに応じて遅滞なく回答します。問い合わせ先はサポートに掲載しています。

2取得する情報

本サービスは、実名・電話番号・住所の入力を求めません。運営者が取得する情報は次のとおりです。

入力する方情報
参加者ニックネーム、アイコンの選択、主役との関係・チーム（任意）、クイズの回答と回答に要した時間、正解数、ビンゴカードと開けたマス、寄せ書き、主役への質問案
幹事会の設定、問題、主役の名前、主役の写真、景品の名称・画像・購入リンク、AI による問題の候補の作成のために入力した主役についての事実（候補の作成にだけ使い、保存しません）
主役主役に関する問題への回答
利用権を購入した方人数区分、金額、購入日時、取引番号
問い合わせをした方返信先のメールアドレス、問い合わせの種類と内容、参加コード（任意）
  • 決済情報　クレジットカード番号などの決済情報とメールアドレスは、購入画面から決済事業者（Stripe・RevenueCat）が直接取得します。運営者はカード番号を取得しません。
  • 端末の保存領域　ブラウザの保存領域（localStorage）に、参加者番号・幹事の鍵・主役の鍵を保存します。これらは同じ端末で会に戻るために利用し、本サービスの通信にのみ使用します。
  • IP アドレス　運営者は、参加コードの総当たりなどの不正利用を防ぐため、通信元の IP アドレスごとの回数をサーバーのメモリ上で一時的に数えます。運営者はこれを記録・保存しません。なお、本サービスの基盤である Cloudflare は、通信の処理と安全確保のために IP アドレスを取り扱うことがあります。

3利用目的

  1. 会を開催し、ゲームを進行し、参加者のスマートフォンと会場のスクリーンに表示するため
  2. 利用権の購入を確認して会に反映し、返金および問い合わせに対応するため
  3. 不正利用（参加コードの総当たりなど）を防止するため
  4. 問い合わせを受けた不具合について、該当する会の情報を確認するため

4他の参加者への表示

本サービスの性質上、ニックネーム・アイコン・主役との関係・チーム・正解数・回答に要した時間・ビンゴの順位・寄せ書き・主役の写真は、同じ会の参加者の画面と会場のスクリーンに表示されます。幹事は、参加者の名前を非表示にし、または参加者を会から除外できます。

5保存期間と削除

  1. 会の情報（画像を含みます）は、その会の最終操作日時と利用権の有効期間の満了日時のいずれか遅い日時から30日を経過した時点で、会ごと削除します。
  2. 購入の記録（金額・日時・取引番号）は、決済事業者のもとで、各社の定めに従って保存されます。運営者は、会計および税務の目的で、法令が定める期間、これを参照・保存します。
  3. 問い合わせの内容と返信先のメールアドレスは、対応のために必要な期間保存し、対応を終えた後、不要になった時点で削除します。
  4. 画像は、閲覧した端末のブラウザにキャッシュとして残ることがあります。

6委託と外国にある事業者

運営者は、本サービスの提供のため、次の事業者に個人データの取扱いの一部を委託します。いずれも米国の事業者で、データを保存・処理する国は特定されません。

事業者委託する業務取り扱う情報
Cloudflare, Inc.サーバーとデータの保存、AI による問題の候補の作成（Workers AI。入力は AI の学習に使われません）2 の情報
Stripe, Inc.クレジットカード決済決済情報、メールアドレス、購入内容
RevenueCat, Inc.購入の記録と管理購入内容、会ごとに割り当てる識別番号、購入画面の表示に伴う端末情報
Google LLC問い合わせフォームの提供問い合わせの内容、返信先のメールアドレス

運営者は、これらの事業者が、個人情報の保護に関する法律により個人情報取扱事業者が講ずべき措置に相当する措置を継続的に講ずるための体制を整備していることを、各社の利用規約およびデータ処理に関する定めにより確認したうえで委託し、その実施状況を定期的に確認します。米国の個人情報保護に関する制度は、個人情報保護委員会が公表する外国における個人情報の保護に関する制度等の調査で確認できます。措置の概要は、本人の求めに応じて情報提供します。

7外部送信

本サービスは、Cookie による追跡、アクセス解析ツール、広告配信を利用しません。利用権の購入画面を開くと、購入手続きのため、利用者の端末から RevenueCat および Stripe へ通信が発生します。問い合わせフォームは、Google のサイト（Google フォーム）で開きます。景品の登録画面の「楽天市場で探す」では、入力した言葉を運営者のサーバーから楽天グループ株式会社の商品検索 API に送ります（利用者の端末の情報は送りません）。検索の結果の商品の画像は、利用者の端末が楽天のサーバーから直接読み込みます。

8安全管理措置

  1. 通信は暗号化（HTTPS）します。
  2. 会の情報は会ごとに区分して保存し、幹事の操作は幹事の鍵を保有する端末に限定します。幹事のリンクは再発行でき、再発行後は以前のリンクで操作できません。
  3. 保存する情報を会の運営に必要なものに限定し、保存期間を経過した会は自動で削除します。
  4. 本サービスの管理操作は、運営者に限定します。
  5. 外国の事業者に委託する情報は、その国の制度を把握したうえで取り扱います。

9未成年者・写真・要配慮個人情報

  1. 参加者には未成年者が含まれることがあります。未成年者は、保護者の了解のもとで利用してください。参加に実名は不要で、本人を特定できないニックネームでも参加できます。
  2. 主役の写真は、主役本人の同意を得たうえで、幹事が登録するものとします。主役本人から削除の申出があった場合は、問い合わせ先で受け付け、速やかに削除します。
  3. 寄せ書き・問題・質問案、および AI による問題の候補の作成のために入力する主役についての事実には、病歴、信条など、要配慮個人情報に当たる内容を記載しないでください。

10開示等の請求

保有個人データの利用目的の通知、開示、訂正・追加・削除、利用停止・消去、第三者提供の停止、第三者提供記録の開示の請求は、問い合わせ先で受け付けます。請求の際は、会の参加コードに加え、本人であることを確認するため、幹事の方は幹事のリンクを開いた端末から、参加者の方は参加に使用した端末から、それぞれ画面に表示される情報を添えてください。確認ができない場合は、追加の確認をお願いすることがあります。手数料はいただきません。会からの除外は、幹事に依頼することもできます。

11改定

本ポリシーを改定する場合は、改定の内容と日付を本サイトに掲載します。

問い合わせ先はサポートに掲載しています。
